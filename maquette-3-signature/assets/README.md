# Photos du salon — maquette 3

Déposez les photos ici sous ces **noms exacts** (JPG ou WebP, renommez si besoin) :

| Fichier | Photo attendue | Cadrage conseillé |
|---|---|---|
| `salon-vitrine.jpg` | La devanture / la pièce vue depuis l'entrée | portrait ou carré, ~1600 px de large |
| `salon-fauteuil.jpg` | Le fauteuil Chesterfield en cuir cognac | carré, ~1200 px |
| `salon-miroir.jpg` | Le miroir en bois et la console | portrait 4:5, ~1600 px de large |

Ces trois images sont appelées en `background-image` dans `../index.html`.
Tant qu'un fichier est absent, le bloc affiche simplement l'aplat sable de la
charte : la page reste propre, aucune icône d'image cassée.

Pensez à compresser avant de committer (viser < 300 Ko par image) — le site
n'a pas de pipeline d'optimisation.
